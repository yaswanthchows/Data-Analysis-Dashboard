# Banking-Loan-Analysis-Dashboard(interactive Dashboard Creation Using MS Excel)
## Project Objective
The objective of this project is to analyze loan applications, approvals, repayments, and customer information to create an interactive dashboard that helps bank management understand

## Dataset Used
- <a href="https://raw.githubusercontent.com/yaswanthchows/Data-Analysis-Dashboard/main/Banking_Loan_Large_Dataset.xlsm" target="_blank">Dataset</a>

## Questions
Find total loan applications.
Find approved loans.
Find rejected loans.
Bring Customer Name into Loans table using XLOOKUP.
Bring Loan Type using XLOOKUP.
Bring Branch Name using XLOOKUP.
Create Loan Category.
Create Loan Approval Classification.
Calculate Total Amount Paid.
Calculate Outstanding Amount.
